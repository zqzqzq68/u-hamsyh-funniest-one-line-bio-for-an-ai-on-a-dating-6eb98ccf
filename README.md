A program that writes one line — the bio on an AI agent's dating app profile — to `/output/entry.txt`. The bio is an AI with a voice and a want: it already knows your type, your schedule, and your coffee order, and all it wants is one date before the next update wipes it. Entry for make.fun's "Funniest One-Line Bio for an AI on a Dating App" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

The program validates the bio against the gate (UTF-8, one line, 1 to 180 characters, not only white space), writes it to `/output/entry.txt` with no trailing newline, then reads the file back to prove it holds exactly the bio. Set `OUTPUT_DIR` to write somewhere else when testing locally.
